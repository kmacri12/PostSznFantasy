PostSzn Fantasy

Fantasy football for the NFL postseason, where a team's players are eliminated as their real teams lose. A React single-page app talks to one FastAPI service backed by PostgreSQL. Sign-in is Supabase, and scores come from Tank01. Eight diagrams follow, from the whole system down to each mechanism.

System map

  • The API only verifies Supabase JWTs. It never sees a password, and the member's email comes from the verified token, not the request body.
  • Avatars live in a private Storage bucket that only the API reads, with the service-role key. The browser never talks to Storage.
  • Rate limits and the support limiter are in memory, which assumes one API process. The relay below is what changes if that stops being true.
